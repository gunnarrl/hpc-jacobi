# HPC Jacobi Solver

A learning project for GPU and HPC performance engineering.

Planned progression:

1. Serial CPU Jacobi solver
2. Naive CUDA implementation
3. Performance modeling and Roofline analysis
4. CUDA profiling and optimization
5. Parallel reduction for convergence
6. MPI domain decomposition
7. Multi-GPU execution
8. Communication/computation overlap
9. Performance-portable implementation
